# 💌 Valentine Letter

A small interactive Valentine's letter website.

## Files
- `index.html` — page structure
- `style.css` — design and animations
- `script.js` — envelope opening, moving NO button, and final message

## Put it on GitHub Pages
1. Create a new GitHub repository.
2. Upload these three files.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save.
7. GitHub will give you a public link you can send.

The page is responsive, so it works on a phone too.
